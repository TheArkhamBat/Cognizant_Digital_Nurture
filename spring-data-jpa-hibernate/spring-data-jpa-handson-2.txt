Country Query Methods (Hands-on 1):

@Repository
public interface CountryRepository extends JpaRepository<Country, String> {
    // 1. Contains text (case-insensitive)
    List<Country> findByNameContainingIgnoreCase(String text);
    
    // 2. Contains text + Ascending order
    List<Country> findByNameContainingIgnoreCaseOrderByNameAsc(String text);
    
    // 3. Starts with a specific alphabet
    List<Country> findByNameStartingWithIgnoreCase(String alphabet);
}

StockRepository (Solutions to all 4 queries):

@Repository
public interface StockRepository extends JpaRepository<Stock, Integer> {
    // 1. FB stock in Sept 2019
    List<Stock> findByCodeAndDateBetween(String code, Date from, Date to);

    // 2. Google stock where close > 1250
    List<Stock> findByCodeAndCloseGreaterThan(String code, double price);

    // 3. Top 3 highest volumes (all codes)
    List<Stock> findTop3ByOrderByVolumeDesc();

    // 4. Three dates when Netflix stocks were lowest (lowest close)
    List<Stock> findTop3ByCodeOrderByCloseAsc(String code);
}
